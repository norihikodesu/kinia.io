スマホを持つお子さんと使いたい方へ
帰宅の確認や迎えの待ち合わせに、通知と地図をどう使うかを紹介します。

子どもの帰宅を、通知で確認。

対象は13歳以上です。Android 8.0以上の端末とGoogleアカウントが必要です。

学校や塾への到着と出発が、通知で届きます。アプリを開かなくても確認でき、迎えの待ち合わせなど必要なときは現在地や移動履歴も見られます。詳しい位置を互いに見るには、双方が相手に「すべて共有」を選びます。

Daily updates

到着と出発が、通知で届く

学校・自宅・塾などを登録しておくと、出入りのたびに通知が届きます。届く通知は、こんなイメージです。

KINIA 通知
📍 太郎 →「学校」に到着
📍 太郎 →「学校」から出発
📍 太郎 →「塾」に到着
📍 太郎 →「自宅」に帰宅

「学校に着いた」「塾を出た」「家に帰った」。毎回の到着連絡や、返事を待つ時間を減らせます。通知や位置の更新は、通信・権限・端末の設定によって遅れたり届かなかったりすることがあります。地図を見るときは更新時刻も確認してください。

Before you start

始める前に、家族で決めること

😰

どの場面で使うか

帰宅の確認、塾への到着、迎えの待ち合わせ。いま連絡が手間になっている場面を一つ選ぶところから始められます。

📱

どこまで共有するか

詳しい位置まで見るのか、登録した場所の出入りだけ知らせ合うのか。お子さんと設定画面を見ながら決めてください。

🔓

データはどう扱われるか

位置情報や表示名の保存先、共有先、削除方法を、使い始める前に確認できます。

💸

料金はかかるか

基本機能は無料で、アプリ内広告はありません。通信料は別途かかります。

必要な共有範囲は、ご家庭や使う場面によって異なります。
まずは、よく使う場所や連絡を減らしたい場面を家族で選んで設定してください。

Features

KINIAでできること

  • 📍

    到着・出発を通知で確認

    学校・自宅・塾などを通知エリアに登録すると、出入りが通知で届きます。共有の設定は相手ごとに行い、保存したら相手の画面でも表示を確かめてください。設定するときは 共有設定の注意点 もご覧ください。

  • ⚖️

    迎えのときは、互いの位置を確認

    双方が相手に「すべて共有」を選ぶと、詳しい現在地と履歴を互いに見られます。どちらかが「通知エリアのみ」なら、控えめなほうの設定が互いに適用されます。

  • 👣

    歩数は日々の活動の目安に

    歩数や更新状況をもとにした「元気度」を確認できます。日々の活動の目安で、健康状態や無事を判定するものではありません。

  • 🔒

    データの扱いを確認できる

    位置や表示名などの情報は、家族への表示と同期のため、サービス側でも扱います。保存・共有・削除については データの取り扱い で説明しています。

  • 🆓

    基本機能は無料

    現在提供している機能は、引き続き無料で使えます。今後、追加機能を有料で提供する予定です。アプリ内広告はなく、通信料は別途かかります。利用する外部サービスは データの取り扱い をご確認ください。

Security

お子さんの位置情報の扱い

お子さんの位置情報は、特に慎重に扱うべき個人データです。KINIAが扱う情報と、共有・保存・削除の方法を確認してから使い始めてください。

✓家族と共有する内容を設定で選ぶ
✓設定後は相手の画面でも表示を確認
✓位置や表示名などをサービス側でも扱う
✓Android版はGoogleアカウントでログイン
✓基本機能は無料で使えます。

データの保存と共有には、外部サービスも利用しています。保護の方法と制約は データの取り扱い にまとめています。

Getting started

親子で使い方を決める

学校、部活、塾、休日の外出。どの場面で通知や地図が役立つかを、お子さんと一緒に確認してください。

たとえば、帰宅を通知で確認するところから。
迎えを待つ日は、親子で互いの位置を確認する使い方もできます。
  • 💬

    通知を受け取る場所を選ぶ

    学校・自宅・塾など、出入りを知りたい場所を通知エリアに登録します。到着と出発のどちらを受け取るかも、使い方に合わせて設定します。

  • 🤝

    迎えを待つ側も、向かう側も

    お子さんが待ち合わせ場所に近づいたら、家を出る。お子さんは、迎えの車がいまどのあたりかを確認する。運転中で返信しにくいときにも役立ちます。

  • 📊

    共有の設定は、あとから変えられる

    共有の設定は相手ごとに行い、本人があとから変更できます。時間で自動的に切り替わる機能はないため、使い方を変えるときは設定を見直してください。

  • 🤝

    使えるのは13歳以上

    KINIAの対象は13歳以上です。中学生でも、13歳未満の方は利用できません。共有する範囲をお子さんと話し合ってから始めてください。

帰宅の確認を、家族で手軽に

KINIAはGoogle Playで配信中です（Android対応、iOS版は準備中）。お子さんと一緒に、よく使う場所を登録するところから始められます。基本機能は無料で、アプリ内広告はありません。
